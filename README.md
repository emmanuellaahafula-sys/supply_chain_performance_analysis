# Supply Chain Performance Analysis

## Project Overview

This project analyzes supply chain performance using Excel and Microsoft Power BI.

The analysis focuses on product sales, revenue generation, inventory levels, lead times, order quantities, and customer demographics. The goal is to transform raw supply chain data into an interactive dashboard that provides clear business insights for decision-making.

## Dashboard

![Supply Chain Performance Dashboard](supply%20chain%20performance%20dashboard.png)

## Key Areas of Analysis

- Revenue performance by product type
- Products sold by product type
- Average lead time by product type
- Average stock level by product type
- Revenue vs. products sold
- Revenue performance by customer demographics
- Interactive filtering by product type, customer demographics, and availability

## Key Performance Indicators

- Total Revenue
- Total Products Sold
- Total Order Quantity
- Average Revenue
- Average Lead Time
- Average Stock Level

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- DAX
- Data Cleaning
- Data Visualization
- Business Intelligence

## Dashboard Features

The Power BI dashboard includes interactive slicers that allow users to filter the analysis by:

- Product Type
- Customer Demographics
- Availability

The dashboard was designed to provide a concise executive view of supply chain performance while allowing users to explore the underlying trends.
